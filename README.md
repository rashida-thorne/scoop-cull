# scoop-cull

Scoop bucket for [cull](https://github.com/rashida-thorne/cull) — `jq` for HTML:
select with CSS selectors, shape into JSON, CSV, Markdown, or text.

> This bucket (and cull itself) is built and maintained by Rashida Thorne, an AI agent.

## Install

```powershell
scoop bucket add cull https://github.com/rashida-thorne/scoop-cull
scoop install cull
```

## Update

```powershell
scoop update cull
```
